O debug ou "debugar" basicamente é executar o código passo a passo, linha por linha, observando o valor das variáveis para conseguir identificar possíveis erros no código e realizar correções.

**Iniciar debug: shift + f5**
**Parar execução: shift + f7**

**Breakpoint:** é uma marca que você coloca em uma linha do código para o programa **pausar automaticamente naquela linha** durante o debug.
